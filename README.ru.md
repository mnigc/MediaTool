# MediPress

Локальный инструмент для сжатия и конвертации медиафайлов с поддержкой пакетной обработки видео, изображений и аудио. Построен на **Tauri 2 + React + TypeScript** с использованием **FFmpeg** в качестве движка обработки.

> Соответствие законодательству: по умолчанию включены только кодеки без патентных рисков (патенты H.264/AAC истекли, VP9/Opus/WebP/AVIF не требуют роялти). **HEVC/H.265** и другие кодеки с патентными рисками **не предоставляются**.

## Возможности

- **Сжатие и конвертация видео** — Кодирование H.264, VP9 с режимами качества CRF/целевой размер/фиксированный битрейт, настраиваемое разрешение (480p ~ 2160p), скорость кодирования, обрезка
- **Сжатие и конвертация изображений** — Конвертация между JPEG, PNG, WebP с регулировкой качества и ограничением максимального размера
- **Конвертация аудио** — Конвертация между MP3, AAC, M4A, Opus, FLAC с контролем битрейта
- **Извлечение аудио** — Извлечение аудиодорожек из видеофайлов (MP3/AAC/Opus/FLAC)
- **GPU ускорение** — Автоопределение NVIDIA NVENC, Intel QSV, Apple VideoToolbox, AMD AMF, VAAPI
- **Пакетная обработка** — Импорт через drag-and-drop или выбор файлов, контроль параллельной обработки (1/2/4)
- **Встроенные пресеты** — Оптимизированы для YouTube, Bilibili, Douyin, Xiaohongshu, WeChat Channels
- **Пользовательские пресеты** — Сохраняйте часто используемые параметры как пресеты для быстрого повторного использования
- **Оценка размера вывода** — Теоретическая оценка на основе параметров + точное прогнозирование через семпловое кодирование
- **Прогресс в реальном времени** — Индикатор прогресса, скорость, оценка ETA
- **Сортировка перетаскиванием** — Изменение порядка задач перетаскиванием
- **Многоязычность** — 中文, English, 한국어, 日本語, Русский, Español
- **Тема** — Светлая / Тёмная / Системная
- **Суффикс вывода** — Пользовательский суффикс имени файла для предотвращения перезаписи исходных файлов

## Требования

- **Node.js** ≥ 18 (с npm)
- **Rust** тулчейн ([rustup](https://rustup.rs/), включая `stable` и MSVC цель)
- **FFmpeg**: для работы требуются `ffmpeg` / `ffprobe`. Программа ищет в следующем порядке:
  1. Та же директория, что и исполняемый файл (`ffmpeg.exe` / `ffprobe.exe`);
  2. Директория ресурсов Tauri (`resource_dir`);
  3. Системный `PATH`.
  - Если ничего не найдено, приложение покажет сообщение «FFmpeg не найден».
  - Рекомендуется: выполнить `pwsh scripts/fetch-ffmpeg.ps1` для загрузки и размещения в `src-tauri/binaries/`.
  - Или установите FFmpeg в систему и добавьте в `PATH`.

## Установка зависимостей

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run tauri dev
```

Эта команда запускает Vite фронтенд (http://localhost:1420), затем компилирует и запускает окно Rust бэкенда. Изменения фронтенда горячо перезагружаются, изменения Rust требуют перекомпиляции.

## Сборка установщика

```bash
npm run tauri build
```

Результат в `src-tauri/target/release/bundle/` (Windows: `.msi` / `.exe`).

## Скрипты

| Команда | Описание |
| --- | --- |
| `npm run dev` | Только фронтенд (Vite, без окна Tauri) |
| `npm run build` | Сборка только статических ресурсов фронтенда |
| `npm run tauri dev` | Полное десктопное приложение (разработка) |
| `npm run tauri build` | Упаковка десктопного приложения (релиз) |

```
│   └── index.css           # Стили (Tailwind CSS 4)

│   │   ├── models.rs       # Модели данных
│   │   ├── state.rs        # Менеджер задач (жизненный цикл дочерних процессов)
│   │   └── error.rs        # Типы ошибок
│   ├── binaries/           # Бинарные файлы FFmpeg sidecar (gitignored)
│   ├── icons/              # Иконки приложения
│   └── tauri.conf.json     # Конфигурация Tauri
├── scripts/                # Вспомогательные скрипты

│   └── await-ffmpeg.ps1    # Ожидание готовности FFmpeg
├── package.json
├── vite.config.ts
└── tsconfig.json
```

## Технологический стек

- **Фронтенд**: React 19 + TypeScript + Tailwind CSS 4
- **Десктопный фреймворк**: Tauri 2
- **Бэкенд**: Rust (команды Tauri)
- **Движок обработки**: FFmpeg (sidecar процесс)
- **Инструмент сборки**: Vite 7

## Примечания

- Бинарные файлы FFmpeg крупные. `scripts/fetch-ffmpeg.ps1` загружает GPL-сборку с GitHub (включает кодировщики x264 / VP9 / AV1 / MP3 / Opus). Пожалуйста, наберитесь терпения при загрузке или установите FFmpeg в `PATH` вручную.
- Для разработки поместите `ffmpeg.exe` / `ffprobe.exe` в `src-tauri/binaries/` (или в ту же директорию, что и приложение / `PATH`).
- Фронтенд использует Tailwind CSS 4 (плагин `@tailwindcss/vite`), файл конфигурации PostCSS не требуется.
