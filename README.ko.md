# MediaTool

**미디어 워크플로 전체를 로컬 앱 하나로.** 웹 다운로드·라이브 녹화, 비디오·오디오 압축 및 변환, 여러 단계를 잇는 자동 파이프라인, 완성 결과의 지정 위치 업로드까지 — 클라우드도 계정도 필요 없습니다. 직접 설정한 업로드 대상을 제외하면 데이터는 절대 기기 밖으로 나가지 않습니다. 엔진은 FFmpeg.

## ✨ 기능

### 📥 웹 다운로드 & 라이브 녹화

- **비디오 다운로더** — yt-dlp 기반, YouTube·Bilibili·틱톡/더우인·X(Twitter)·Instagram·Twitch·weibo(웨이보)·Vimeo 등 수천 개 사이트 지원. 최고 품질 또는 해상도 지정 가능.
- **라이브 녹화** — Streamlink 기반, YouTube·Twitch·Bilibili·더우어(斗鱼)·후야(虎牙)·Kick·NicoLive 등 약 155개 플랫폼.
- **라이브 모니터** — 채널을 등록해 두면 방송이 시작되는 순간 자동 녹화 시작.

### 🎬 비디오 도구

- **압축** — H.264·HEVC·VP9·AV1(SVT-AV1), CRF/고정 비트레이트/*목표 파일 크기* 3가지 품질 모드, 해상도·프레임 레이트·인코딩 속도 프리셋.
- **변환** — 컨테이너·코덱 자유 조합(MP4·MKV·WebM·MOV × H.264·HEVC·VP9·AV1). 컨테이너 전환 시 코덱 자동 매칭.
- **트림** — 다중 구간 잘라내기, 무손실(키프레임 정렬) 또는 정밀 재인코딩 모드.
- **자막** — 외부 자막 하드코딩 또는 소프트 녹입.
- **병합** — 여러 클립을 하나의 비디오로 연결.
- **속도 변경** — 0.25×~4×, 오디오 피치 유지, 음소거 선택 가능.
- **워터마크** — 이미지 오버레이, 9분할 위치·크기·여백·불투명도 조절.
- **스크린샷 & 프레임 추출** — 단일 프레임/간격 연속 PNG·JPEG 내보내기, 프레임 샘플링 타임랩스 비디오, 썸네일 매트릭스(콘택트 시트) 생성.
- **오디오 트랙 제거** — 스트림 복사 무손실 음소거.
- **무음 감지** — 역치·최소 길이 조건으로 무음 구간을 찾아 보고서로 내보내기.
- **미디어 검사** — 모든 파일의 완전한 ffprobe 보고서, 메타데이터 삭제는 원클릭.

### 🎧 오디오 도구

- **압축 / 변환** — MP3·AAC·M4A·Opus·FLAC 간 자유 변환, 비트레이트 지정.
- **오디오 추출** — 비디오에서 무손실 또는 재인코딩으로 분리.
- **볼륨** — 라우드니스 정규화 또는 수동 게인.
- **병합** — 여러 오디오 파일 연결.

### 🔗 자동 파이프라인

- **워크플로 빌더** — 여러 도구를 재사용 가능한 파이프라인으로 연결, 이전 단계 결과가 다음 단계 입력이며 진행률은 하나의 바로 표시.
- **완료 후 후처리** — 다운로드·녹화·작업에 파이프라인을 바인딩하면 완료 직후 자동 실행.
- **스마트 폴백** — 무손실 remux가 컨테이너에 맞지 않으면 자동으로 올바른 트랜스코딩으로 전환하고 사유를 안내.

### ☁️ 완성 후 바로 업로드

- 결과물을 **WebDAV**(지안궈윈·NAS·Alist…), **Telegram**, **YouTube**, **Google Drive**, **OneDrive**로 전송.
- 스트리밍 전송, 실시간 진행률, 취소 가능, OAuth 토큰 자동 갱신 — 자격 증명은 앱 프런트엔드에만 저장되고 백엔드에는 남지 않습니다.

### ⚡ 일괄 처리도 질서 있게

- 수십 개 파일을 드래그해 **도구를 넘어 병렬 실행**.
- 통합 작업 독: 진행률·속도·남은 시간·재시도·취소, 드래그 정렬 지원.
- **이름 충돌 정책**(자동 변경 / 건너뛰기 / 덮어쓰기)과 출력 접미사 커스터마이징 — 원본 파일이 실수로 덮어써지는 일은 없습니다.
- **결과 크기 예측** — 이론 추정 + 실제 샘플 인코딩의 정밀 예측.

### 🎛 품질과 속도를 위해

- **GPU 인코딩 자동 감지** — 시작 시 NVIDIA NVENC·Intel QSV·Apple VideoToolbox·AMD AMF·VAAPI를 탐지해 원클릭으로 활성화.
- **프리셋** — 도구별 내장 레시피와 나만의 사용자 프리셋.

### 🔒 프라이버시 우선

- 100% 로컬 처리 — 업로드 대상을 설정하지 않는 한 데이터는 기기 밖으로 나가지 않습니다.
- **자동 업데이트**로 재설치 불필요.
- UI는 **中文 / English** 지원, 라이트·다크 테마.
