# MediaTool

**メディアワークフロー全体を、ひとつのローカルアプリに。** Webからのダウンロード・ライブ録画、動画・音声の圧縮と変換、複数ステップを繋ぐ自動パイプライン、処理完了後の指定先へのアップロードまで — クラウドもアカウントも不要。自分で設定したアップロード先を除き、データは一切マシン外へ出ません。エンジンは FFmpeg。

## ✨ 特徴

### 📥 Webダウンロード & ライブ録画

- **動画ダウンロード** は yt-dlp 対応。数千サイト：YouTube、Bilibili、TikTok/抖音、X (Twitter)、Instagram、Twitch、Weibo、Vimeo など。最高画質または解像度指定が可能。
- **ライブ録画** は Streamlink 対応。YouTube、Twitch、Bilibili、斗魚、虎牙、Kick、NicoLive など約155プラットフォーム。
- **配信モニタ** — チャンネルを登録しておくと、配信が始まった瞬間に自動で録画を開始。

### 🎬 動画ツール

- **圧縮** — H.264 / HEVC / VP9 / AV1 (SVT-AV1)。CRF・固定ビットレート・*目標ファイルサイズ* の3モードに加え、解像度・フレームレート・速度プリセット。
- **変換** — コンテナとコーデックの組み合わせ自由（MP4 · MKV · WebM · MOV × H.264 · HEVC · VP9 · AV1）。コンテナ変更でエンコーダも自動整合。
- **トリム** — 複数区間の切り出し。ロスレス（キーフレーム合わせ）または精密再エンコード。
- **字幕** — 外部字幕の焼き込みまたはトラックとしての封入（ソフト字幕）。
- **透かし** — 画像オーバーレイ、9分割位置・拡大縮小・余白・不透明度を調整。
- **スクリーンショット & フレーム抽出** — 単一フレームや間隔指定の連番出力（PNG/JPEG）、間引き抽出によるタイムラプス動画、サムネイル一覧（コンタクトシート）生成。
- **音声トラック除去** — ストリームコピーによるロスレス静音化。
- **無音検出** — 閾値と最小有音時間で無音区間を特定しレポート出力。
- **メディア検査** — あらゆるファイルの ffprobe 詳細レポート、メタデータ削除もワンクリック。

### 🎧 音声ツール

- **圧縮 / 変換** — MP3・AAC・M4A・Opus・FLAC を任意ビットレートで相互変換。
- **音声抽出** — 動画からロスレスまたは再エンコードで音声を分離。
- **音量** — ラウドネス正規化またはゲイン調整。
- **結合** — 複数音声ファイルの連結。

### 🔗 自動パイプライン

- **ワークフロー構築** — 複数のツールを繋いで再利用可能なパイプラインに。前のステップの出力が次の入力になり、進捗は1本のバーで表示。
- **完了後処理** — ダウンロード・録画・ジョブにパイプラインを紐付けると、完了直後に自動実行。
- **スマートフォールバック** — ロスレス remux がコンテナに収まらない場合は、自動で適切なトランスコードに切替え、理由も通知。

### ☁️ 完了したらそのままアップロード

- 完成ファイルを **WebDAV**（Nutstore・NAS・Alist…）、**Telegram**、**YouTube**、**Google Drive**、**OneDrive** へ送信。
- ストリーミング転送・リアルタイム進捗・キャンセル可能・OAuthトークン自動更新 — 認証情報はアプリ前面のみに保存し、バックエンドには残しません。

### ⚡ バッチも秩序ある

- 数十ファイルをドラッグ投入し、**ツール横断で並列実行**。
- 統合タスクドック：進捗・速度・残り時間・再試行・キャンセル、ドラッグ並べ替え対応。
- **名前衝突ポリシー**（自動リネーム / スキップ / 上書き）とカスタム接尾辞 — 元ファイルがうっかり上書きされることはありません。
- **サイズ予測** — 理論見積もり＋実サンプリングエンコードによる精密予測。

### 🎛 品質と速度のために

- **GPUエンコード自動検出** — 起動時に NVIDIA NVENC / Intel QSV / Apple VideoToolbox / AMD AMF / VAAPI を自動判定し、ワンクリックで有効化。
- **プリセット** — ツール別の標準レシピと、自分だけのカスタムプリセット。

### 🔒 プライバシー設計

- 100% ローカル処理 — アップロード先を設定しない限り、データはマシン外へ出ません。
- **自動アップデート** で再インストール不要。
- UIは **中文 / English** の2言語、ライト・ダークテーマ対応。
